Miqu Project
GitHub

A unified, sovereign Wayland desktop ecosystem and native applications built from first principles in modern C++.

Core Architecture

miquland Compositor

Sovereign Wayland compositor built with wlroots and modern C++20.
miqutoolkit Framework

Declarative C++ GUI toolkit powering all ecosystem components.

Native Linux Applications

MiquSecure Security

Privilege authorization and security policy manager.
MiquMusic Audio

Low-latency audio player and MPD companion.
MiquGallery Media

Hardware-accelerated, responsive image viewer.
MiquInfo System

Real-time system monitor & hardware diagnostics.

Desktop Shell & Utilities

Integrated shell components sharing the miqutoolkit design system:

miqudeskbar miqulauncherrun miquoverviewswitch miqulocklock miquidleidle miqubgwall miqupolkitauth miqudmlogin miqutesttest

Mobile Companions

Doctor Android

Medical diagnostics and clinical management companion.
