Sovereign Wayland Desktop Ecosystem

High-Performance Wayland Native Computing

Engineered from first principles in modern C++20. A custom wlroots tiling compositor, a dedicated declarative UI toolkit, and a cohesive native application suite.

⚡ Zero UI Fragmentation

Every application uses the shared miqutoolkit framework. No mismatched widgets or conflicting styling runtimes.

🛡️ Uniform Two-Tier Config

Zero auto-seeding. Direct system fallback with single-file user authority and safe timestamped archiving (.bak.<timestamp>).

🎨 Dynamic Theming via Source

Decoupled from hardcoded C++ logic. Dynamic theme propagation from miqutheme works transparently via standard config sourcing.

Core Foundation

miquland

Compositor

High-performance Wayland window manager built with wlroots and SceneFX. Features dynamic spiral/stack tiling, real-time corner rounding, drop shadows, Gaussian layer blurs, and IPC controller support.

C++20 wlroots SceneFX

miqutoolkit

UI Toolkit

Shared C++20 declarative UI framework powering all desktop apps. Provides Android-inspired layout containers, Cairo/Pango vector rendering, atomic inotify live reload, and Wayland surface abstractions.

Declarative UI Cairo / Pango Design Tokens Atomic Staging
