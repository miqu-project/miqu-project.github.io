Ecosystem Overview

miqu-project contains its core attraction, miquland, which is a Wayland compositor featuring animations, blur, and visual effects built with scenefx, wlroots, and C++20. It is paired with a dedicated application development toolkit, miqutoolkit (built on Cairo & Pango), which powers 16 native desktop applications and tools targeting a complete, unified Linux desktop environment, alongside Android companion applications integrated across the ecosystem.

The parent organization link is available above on GitHub. Quick intro, documentation, and links to each GitHub repo can be found here. For more details, read the specific README in each repo or consult the documentation.

Installation & Launch Workflow

Getting started follows a familiar standalone Wayland workflow: start from a clean Arch Linux (or Debian / Fedora) base system. From your virtual console (TTY), clone this workspace repository and run the build scripts to compile the entire ecosystem or individual targets.

Once installed, simply launch miquland directly from your TTY. If you use a graphical display manager (SDDM, GDM, or miqudm), your login manager will also show miquland in the session options. If you are switching from Hyprland or Sway, exit to your shell prompt and invoke the compositor—it adheres to the exact same lightweight, display-manager-optional lifecycle.

Development Philosophy & Safety

LLM Use, Engineering & Safety

Addressing AI skepticism with architectural rigor: how context-aware scaffolding empowers human architects, backed by strict C++20 memory safety and open-source sovereignty.

AGENTS.md Specification ↗

Engineering Philosophy & Authorship

Continuum of Abstraction
Scaffolding

From Compilers to Protocol Synthesizers

Compilers (FORTRAN, C) automated machine code without reducing developer authorship. In Wayland, wayland-scanner already synthesizes hundreds of C boilerplate lines from XML. Directing an LLM to generate listener structs and Cairo geometry calculations is context-aware scaffolding; true engineering remains state machine verification, event synchronization, and lifecycle discipline.

Architect vs. Synthesizer
Authorship

Redefining Systems Authorship

An architect designs load-bearing distributions and blueprints spatial ergonomics without personally mixing every cubic yard of concrete. In Miqu, the LLM is the modern power tool; the developer is the system architect authoring the contracts, enforcing the Two-Tier Single-File Authority doctrine, and guaranteeing protocol invariants.

Architectural Pragmatism
The Sweet Spot

Knowing What Not to Invent

Miqu does not reinvent the Linux kernel, base packaging (Arch, Debian, Fedora), or cryptography. Adhering to the Unix philosophy, we integrate battle-tested backends: ufw/nftables in miqusecure, Linux PAM in miqudm, systemd-logind in miqulock, and standard NetworkManager D-Bus interfaces.

Open Wayland Standards
Anti-Lock-In

Strict Protocol Sovereignty

Universal protocol adherence (xdg-shell, wlr-layer-shell-v1, ext-session-lock-v1) guarantees component interchangeability. Users can freely swap in waybar, rofi, or swaylock with zero proprietary lock-in.

Security, Threat Modeling & Memory Safety

Zero Cloud & Telemetry
100% Local

Complete Privacy Sovereignty

Zero analytics, zero telemetry, and zero mandatory cloud services. The desktop runs completely offline. Network activity occurs strictly when explicitly triggered (e.g., MPD streaming or package searches). All code is fully open and auditable.

Strict C++20 RAII
Memory Safety

Deterministic Confinement

Raw owning pointers are banned. All file descriptors, Cairo contexts, and Wayland listeners are wrapped in scope-bound RAII guards with custom deleters. UI mutations are strictly confined to the main Wayland thread, with worker isolation via eventfd and pipes.

Tri-Tier Verification
Pipeline

Defense-in-Depth Validation

Code is never blindly accepted. It moves through Model Synthesis (guided by strict interface contracts) → Deterministic Tooling (-Wall -Wextra, ASan, UBSan, cppcheck) → Human Architectural Review on live Wayland hardware.

Codebase Audits & Contribution Governance

The Continuous Audit Pipeline
Verification

Vulnerability Scans & Blast-Radius Analysis

The entire codebase across all repositories undergoes periodic automated scans targeting security vulnerabilities, AGENTS.md non-conformance, memory leaks, and dead/junk abstractions.

Findings are cross-checked by independent review agents to author an authentic implementation plan. Before edits are applied, a system-wide blast-radius analysis models cross-component ripple effects (from the compositor down through miqutoolkit and applications). Edits are subjected to heavy test compilation with runtime sanitizers (ASan/UBSan), and only committed after explicit human architectural sign-off.

Single-Maintainer Stewardship
Architecture

Preserving Invariant Uniformity

Building a cohesive 16-app desktop suite requires unyielding adherence to core contracts: the Two-Tier Single-File Authority doctrine, strict RAII, main-thread Wayland confinement, and zero hidden C++ magic. Diverse external PRs frequently introduce fragmented patterns or conflicting long-term visions.

To maintain absolute architectural purity, miqu-project maintains a single-author commit model. However, the ecosystem deeply values community engagement: volunteers are warmly welcomed to participate as code reviewers, security auditors, issue reporters, and testers to scrutinize the codebase alongside us.

The Closed-Source Asymmetry & The Double Standard of AI Scrutiny

Open-Source Transparency vs. Proprietary Opacity

The epitome of software engineering—Google, Microsoft, and industry leaders—have publicly confirmed that an enormous, rapidly increasing percentage of their internal code is synthesized by AI models. Yet if critics object to AI-assisted code, will they stop using YouTube, Windows, macOS, or Google Play Services? How could anyone ever verify proprietary software isn't already "vibecoded"?

You can't. Closed-source giants escape purist criticism purely through opacity—hiding their code behind compiled binaries and NDAs. You are already running AI-synthesized software daily without the ability to inspect it. In Miqu, we choose radical honesty and total sovereignty: every single line of C++20 and Wayland code is 100% open, auditable, and verifiable by you.
