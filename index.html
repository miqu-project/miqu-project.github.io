A unified, sovereign Wayland desktop ecosystem and native applications built from first principles in modern C++.

What is Miqu Project?

Base Distro (Arch/Debian) → Compositor (miquland) → Shell (miqudesk...) → Native Apps (miqumusic...)
Building a Parallel to GNOME & KDE

In Linux, a full Desktop Environment (DE) bundles a Window Manager + Shell + native Apps. We are essentially building an independent parallel to GNOME or KDE from the ground up. We are still evolving and currently utilize standard upstream components like xdg-desktop-portal, but the destination is a complete, sovereign Desktop Environment.

Why We Do Not Build a Base Distro

A base Linux distribution provides the kernel, packages, and environment before you launch a graphical session. Creating an OS distribution is massive work that requires dedicated infrastructure and full-time security teams. Because much of Miqu is AI-assisted and maintained by a single developer, an AI-coded base distro would present serious security, privacy, and supply-chain vulnerabilities. There is no plan nor capacity to build one—Miqu runs on top of trusted distributions like Arch or Debian.

More Than Just a Window Manager

When people say "Window Manager", it rarely describes the full reality (neither Sway nor Hyprland are just bare WMs). Miqu spans its own C++ GUI framework (miqutoolkit), compositor (miquland), integrated shell utilities, first-party Linux apps, and companion Android apps to pioneer a cohesive cross-device ecosystem.
