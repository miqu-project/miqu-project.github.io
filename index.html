Components of miqu-project

All components are plug and play. Miquland is independent of miqutoolkit and miqutoolkit is independent of miquland. If miqutoolkit is installed in any wayland compositor e.g. hyprland, all the miqu-linux apps will run natively. Alternatively one can only use Miquland and not install miqutoolkit and miqu-linux apps rather may use waybar, rofi etc. Miquland treats them all the same.

Quick Installation

Option 1: Recursive Workspace 
git clone --recurse-submodules https://github.com/miqu-project/miqu-project.git
cd miqu-project
sudo ./install_all.sh
Option 2: Individual Build / CMake 
git clone https://github.com/miqu-project/miquland.git
cd miquland
./make.sh         # local build
sudo ./make.sh   # system install (/usr)

cmake -B build -DCMAKE_INSTALL_PREFIX="/usr"
cmake --build build -j"$(nproc)"
sudo cmake --install build
