Miquland

Miquland is a dynamic tiling window manager and compositor for Wayland built with wlroots and SceneFX.

Source Repository: github.com/miqu-project/miquland ↗

Dynamic Tiling Layout Engine Layout

Miquland implements intelligent spiral, stack, and floating layout algorithms. Windows automatically split and arrange themselves across workspaces, providing fluid ergonomics with seamless multi-monitor management.

SceneFX Hardware-Accelerated Shaders Visuals

Window decorations are rendered natively on the GPU via wlroots and SceneFX. The compositor delivers real-time corner rounding, soft drop shadows, and dual-pass Gaussian layer blurs without sacrificing frame rates.

IPC Controller & Runtime Dispatch miquctl

Compositor state, workspace transitions, and window dispatching can be queried and controlled programmatically over a dedicated Unix domain socket using miquctl.

source repository github.com/miqu-project/miquland →
Languages: C++20, C
Core Protocols: wlr-layer-shell-v1, ext-session-lock-v1, ext-idle-notify-v1

Miqutoolkit

Miqutoolkit is a shared C++20 declarative UI framework powering all Miqu desktop applications.

Source Repository: github.com/miqu-project/miqutoolkit ↗

Declarative Layout Hierarchy API

Inspired by modern declarative patterns, Miqutoolkit provides structured layout containers like ViewGroup and CardView. User interfaces are declared fluently in C++20 with strict RAII lifecycle management.

Cairo & Pango Vector Rendering Graphics

All controls render through Cairo vector graphics and Pango font layouts onto Wayland shared-memory buffers, ensuring crisp sub-pixel antialiasing and flawless high-DPI scaling across monitors.

Atomic inotify Live Reload Theming

The toolkit monitors active configuration and palette files via inotify. Theme changes and metric updates propagate instantly to all running applications with zero restarts.

example — declarative view creation
auto card = CardView::create()
->set_corner_radius(14)
->set_background(Theme::surface())
->add_child(TextView::create("MiquBar"));

Documentation

The uniform Two-Tier Single-File Authority model governs configuration across all Miqu components.

Architecture Guidelines & Contracts: AGENTS.md on GitHub ↗

1. System Baseline (/usr/share) Tier 1

Every application installs a fully functional default baseline configuration into /usr/share/<app>/<app>.conf. On a fresh installation, applications run directly from this file without polluting the user's home directory.

2. Safe Timestamped Archiving --init-config

When a user invokes <app> --init-config, any existing configuration is never silently overwritten. It is safely archived with a timestamp (.bak.<timestamp>) before a fresh, fully documented template is generated.

3. Standalone User Authority (~/.config) Tier 2

Once ~/.config/<app>/<app>.conf exists, it is loaded exclusively. There is no hidden background merging or implicit inheritance. Dynamic themes are included cleanly through standard source = directives.

Quick Start

Building and installing the Miqu desktop environment on Arch Linux.

Master Repository & Scripts: github.com/miqu-project/miqu-project ↗
single-command installation
$git clone --recurse-submodules https://github.com/miqu-project/miqu-project.git
$cd miqu-project
$./install_all.sh

Single-Command Ecosystem Installation install_all.sh

The install_all.sh script orchestrates a topological build across the entire stack: first compiling the miquland compositor, then installing the miqutoolkit shared library, and finally building the complete native application suite.

Local Test Builds & Non-Root Workflows make.sh

Every component contains an independent make.sh script. Running ./make.sh as an unprivileged user configures and compiles locally into build/ for rapid development without touching system directories.

About Us

"A fully functional Desktop Environment is the goal, but we are slowly making progress."

GitHub Organization: github.com/miqu-project ↗

Full-Stack Sovereignty Core Value

We design, build, and maintain every layer of the Miqu ecosystem: the compositor, the UI framework, and all native applications. This end-to-end sovereignty eliminates mismatched widget toolkits and styling fragmentation.

First-Principles Craftsmanship C++20

Code across the project adheres to strict standards: small single-responsibility functions, scope-bound RAII memory safety, event-driven thread confinement, and zero pseudo-solutions or hidden magic.

Arch Linux Platform Foundation Platform

Miqu is built and verified on Arch Linux using modern C++20 and standard CMake build protocols.
