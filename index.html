System Architecture

Four Distinct Ecosystem Pillars

Clear boundaries govern the Miqu architecture: the miquland compositor operates independently at the display server layer, while miqutoolkit provides the shared client UI framework that exclusively powers our native desktop applications.

miquland

Compositor

C++20 • wlroots • OpenGL

Independent Wayland compositor & tiling window manager. Manages display outputs, dynamic tiling algorithms, scenefx visual effects, input devices, and IPC hooks. Operates at the display server layer.

miquland repository ↗

miqutoolkit

UI Toolkit

C++20 • Cairo • Pango

Shared client-side UI application toolkit. Powers all downstream desktop applications with unified widgets, event-loop abstraction, responsive geometry, and instant dynamic theme propagation.

miqutoolkit repository ↗

Getting Started

Deploy Miqu on Arch Linux

Build and install the entire ecosystem in strict dependency sequence using the top-level orchestration script. 

# Clone recursive workspace repository
git clone --recurse-submodules https://github.com/miqu-project/miqu-project.git
cd miqu-project

# Run deterministic multi-stage build
./install_all.sh
