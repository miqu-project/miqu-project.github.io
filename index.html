Ecosystem Overview

miqu-project contains its core attraction, miquland, which is a Wayland compositor featuring animations, blur, and visual effects built with scenefx, wlroots, and C++20. It is paired with a dedicated application development toolkit, miqutoolkit (built on Cairo & Pango), which powers 16 native desktop applications and tools targeting a complete, unified Linux desktop environment, alongside Android companion applications integrated across the ecosystem.

The parent organization link is available above on GitHub. Quick intro, documentation, and links to each GitHub repo can be found here. For more details, read the specific README in each repo or consult the documentation.

Installation & Launch Workflow

Getting started follows a familiar standalone Wayland workflow: start from a clean Arch Linux (or Debian / Fedora) base system. From your virtual console (TTY), clone this workspace repository and run the build scripts to compile the entire ecosystem or individual targets.

Once installed, simply launch miquland directly from your TTY. If you use a graphical display manager (SDDM, GDM, or miqudm), your login manager will also show miquland in the session options. If you are switching from Hyprland or Sway, exit to your shell prompt and invoke the compositor—it adheres to the exact same lightweight, display-manager-optional lifecycle.

The Continuum of Engineering Abstraction

The "Boilerplate Spectrum"

From machine code to assembly (1950s) and high-level compilers (FORTRAN, C), automated translation has never diminished developer authorship. As Linus Torvalds and systems history demonstrate, compilers automate transformation—the human remains accountable for logic and semantics.

In modern Wayland, wayland-scanner already synthesizes hundreds of lines of mechanical C boilerplate from XML schemas. Directing an LLM to generate event listener structs and Cairo geometry calculations is context-aware scaffolding; true engineering resides in state machine verification, event synchronization, and memory lifecycle discipline.

The Architect vs. The Synthesizer

Redefining Authorship

A building architect does not manually mix every cubic yard of concrete or chisel every stone. They calculate load-bearing distributions, blueprint spatial ergonomics, enforce building safety codes, and sculpt the structure.

In the Miqu ecosystem, the LLM is the modern power tool; the human developer is the system architect. The engineer authors the architectural contracts, enforces the Two-Tier Single-File Authority doctrine, oversees protocol invariants, and sculpts the desktop experience.

The "Sweet Spot": Architectural Pragmatism

Knowing What Not to Invent

Miqu deliberately avoids reinventing foundational layers: we do not fork the Linux kernel, re-implement distribution packaging (Arch, Debian, Fedora), or author novel cryptography.

Adhering to the Unix philosophy, Miqu integrates battle-tested upstream backends: ufw and nftables in miqusecure, Linux PAM in miqudm, systemd-logind in miqulock, and standard NetworkManager D-Bus interfaces.

Universal Standards & Anti-Lock-In

Protocol Sovereignty

Miqu rejects proprietary lock-in by implementing universal Wayland protocols (xdg-shell, wlr-layer-shell-v1, ext-session-lock-v1, ext-idle-notify-v1).

Every component is hot-swappable: users can freely run waybar or rofi inside miquland, or deploy miqubar on Hyprland or Sway without friction. Every component earns its place purely on performance and UX merit.

Security & Verification

System Safety & Threat Modeling

Directly countering AI skepticism with defense-in-depth: zero cloud telemetry, strict C++20 RAII memory safety, and a deterministic tri-tier verification pipeline.

Safety Contracts in AGENTS.md ↗

Zero Cloud & Zero Telemetry

100% Local Sovereign Operation

Miqu contains zero telemetry, zero analytics, and zero mandatory cloud dependencies. The desktop operates completely offline. Network activity occurs strictly when the user explicitly triggers network actions (e.g., MPD streaming or package searches). All code is fully open and auditable.

Strict C++20 RAII & Confinement

Deterministic Lifecycle Discipline

Memory ambiguities in generated code are eliminated by enforcing strict RAII rules documented in AGENTS.md: raw owning pointers are banned, all file descriptors and Cairo contexts are wrapped in smart pointers with custom deleters, and UI rendering is strictly confined to the main Wayland event loop.

Tri-Tier Verification Pipeline

Defense-in-Depth Validation

Code is never accepted blindly: it advances through Model Synthesis (constrained scaffolding from interface contracts) → Deterministic Tooling (strict compiler warnings, ASan, UBSan, cppcheck) → Human Architectural Review (verifying state machine transitions and live Wayland hardware behavior).
