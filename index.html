Sovereign Wayland Desktop

Unified Desktop Ecosystem Built From First Principles

An independent, cohesive parallel to GNOME and KDE crafted in modern C++20. From the custom Wayland compositor core and GUI framework to first-party shell utilities and native apps.

# Clone and build the sovereign compositor git clone --recurse-submodules https://github.com/miqu-project/miquland.git cd miquland && sudo ./make.sh

Ecosystem Architecture

Base Distro (Arch/Debian) → Compositor (miquland) → GUI Toolkit (miqutoolkit) → Shell & Apps
Parallel to Traditional DEs

In Linux, a full Desktop Environment bundles a Compositor + Shell + Native Apps. Miqu builds this entire unified continuum without the bloat of fragmented desktop layers.

Distro Sovereignty

Miqu runs on top of battle-tested distributions like Arch or Debian, maintaining strict security boundaries while providing a tailored sovereign graphical user space.

Cross-Device Scope

Features our declarative C++ GUI framework (miqutoolkit), compositor (miquland), shell daemons, first-party Linux apps, and Android companions.

Core Foundation

miquland

Compositor

Sovereign Wayland compositor built with wlroots and modern C++20. Powers multi-monitor rendering, window tiling policies, dynamic animations, and IPC control.

Modern C++20 wlroots Wayland Protocols Scene Graph

miqutoolkit

GUI Framework

Declarative C++ GUI toolkit and widget library powering all ecosystem components with unified themes, Cairo/Pango rendering, and Wayland layer-shell bindings.

Declarative UI Cairo / Pango Layer Shell Live Theming
