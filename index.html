Core Compositor

Miquland

Miquland is a dynamic tiling window manager and compositor for Wayland built with wlroots and SceneFX.

Dynamic Tiling

Layout

Intelligent spiral, stack, and floating layout engines with automatic window splitting and multi-monitor management.

SceneFX Shaders

Visuals

Hardware-accelerated window corner rounding, soft drop shadows, and dual-pass Gaussian layer blurs.

IPC Controller

miquctl

Dedicated Unix domain socket IPC protocol for dynamic workspace switching, window queries, and runtime reloads.

source repository github.com/miqu-project/miquland →
Languages: C++20, C
Core Protocols: wlr-layer-shell-v1, ext-session-lock-v1, ext-idle-notify-v1
Shared UI Framework

Miqutoolkit

Miqutoolkit is a shared C++20 declarative UI framework powering all Miqu desktop applications.

Declarative Layout

API

Ergonomic container hierarchy inspired by modern declarative patterns (`ViewGroup`, `CardView`, `TextView`).

Vector Rendering

Cairo & Pango

High-DPI vector rendering, crisp typography, and sub-pixel antialiasing with Wayland shared-memory buffers.

Atomic Live Reload

inotify

Watches configuration and theme files for immediate zero-restart appearance propagation across running apps.

example — declarative view creation
auto card = CardView::create()
->set_corner_radius(14)
->set_background(Theme::surface())
->add_child(TextView::create("MiquBar"));

Architecture Contract

Documentation

The uniform Two-Tier Single-File Authority model governs configuration across all Miqu components.

1. System Baseline

Tier 1

/usr/share/<app>/<app>.conf
Fully functional out of the box. Zero files are automatically created in ~/.config/.

2. Safe Archiving

Init

Running <app> --init-config safely archives any existing config to .bak.<timestamp> before generating a fresh template.

3. User Authority

Tier 2

~/.config/<app>/<app>.conf
Loaded exclusively once it exists. Dynamic themes are included via standard source = lines.
