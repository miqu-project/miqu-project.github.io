The Two-Tier Architecture Doctrine

No background magic, no fragmented cascading merges, and zero home-directory pollution. Every component across the Miqu ecosystem conforms to the identical single-file authority lifecycle.

Tier 1: Baseline

System Authority

/usr/share/<app>/<app>.conf provides a 100% functional out-of-the-box baseline. Zero files are created in ~/.config/ automatically.

Transition

Safe Archiving

Running <app> --init-config safely archives any existing config to .bak.<timestamp> before generating a fresh documented template.

Tier 2: User

Standalone Truth

Once ~/.config/<app>/<app>.conf exists, it is loaded exclusively. Theming is decoupled via explicit source = directives.

$ miqubar --init-config → Archived to .bak.20261018-221430
