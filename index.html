The Three Pillars of Miqu

Eliminating the fragmented toolkits, third-party greeters, and bloated web wrappers that plague modern desktop environments.

🪟

Compositor Core

miquland delivers rock-solid wlroots-based Wayland window management with dynamic tiling layouts, custom IPC protocols (miquctl), and real-time workspace overview plugins.

Unified UI Toolkit

miqutoolkit provides the single authoritative Cairo, Pango, and Wayland UI abstraction across all native apps. Live inotify theme reloading, shared appearance tokens, and zero UI fragmentation.

Deployment

Get Started in Seconds

Miqu is built from the ground up for Arch Linux with automated compilation scripts across every component.

bash — arch-linux
# 1. Clone the core compositor repository
git clone https://github.com/miqu-project/miquland.git
cd miquland

# 2. Build and install miquland & dependencies
sudo ./make.sh

# 3. Clone and install the native application suite
git clone https://github.com/miqu-project/miqu-linux-apps.git
cd miqu-linux-apps && sudo ./install_all.sh
