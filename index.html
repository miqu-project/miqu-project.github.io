Miqu Project

A cohesive, high-performance Wayland desktop ecosystem & native mobile applications.

View on GitHub

Ecosystem Repositories

miquland Compositor

Wayland window manager and compositor core built with wlroots, dynamic tiling layouts, and IPC daemon.

miqutoolkit C++ Toolkit

Shared UI framework providing Cairo, Pango, and Wayland abstractions, widgets, and live theme synchronization.

miqu-linux-apps Desktop Suite

13 integrated native Linux utilities including miqudesk, miqusecure, miqumusic, miqudm, and miqulauncher.

miqu-android Mobile Apps

Android mobile applications and companion tools engineered for the Miqu ecosystem.

Quick Start

Clone the workspace and build the complete Miqu desktop environment on Arch Linux:

git clone https://github.com/miqu-project/miquland.git
cd miquland && sudo ./make.sh
