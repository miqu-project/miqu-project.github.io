miqu-project contains its core attraction, miquland, which is a Wayland compositor featuring animations, blur, and visual effects built with scenefx, wlroots, and C++20. It is paired with a dedicated application development toolkit, miqutoolkit (built on Cairo & Pango), which powers 16 native desktop applications and tools targeting a complete, unified Linux desktop environment, alongside Android companion applications integrated across the ecosystem.

The parent organization link is available above on GitHub. Below you will find the quick architectural breakdown, ecosystem documentation, and links to each individual GitHub repository. For more details, consult the documentation or read the specific README in each repository.

System Architecture

Four Distinct Ecosystem Pillars

Clear boundaries govern the Miqu architecture: miquland operates independently as the Wayland compositor, while miqutoolkit provides the shared client UI framework powering the desktop applications.

GitHub

miquland

Compositor

C++20 • wlroots • OpenGL

Independent Wayland compositor & tiling window manager. Manages display outputs, dynamic tiling algorithms, scenefx visual effects, input devices, and IPC hooks. Operates at the display server layer.

miqutoolkit

UI Toolkit

C++20 • Cairo • Pango

Shared client-side UI application toolkit. Powers all downstream desktop applications with unified widgets, event-loop abstraction, responsive geometry, and instant dynamic theme propagation.

GitHub

Automated System Build

Execute ./install_all.sh from the root workspace to compile and install all components. 

# Clone recursive workspace repository
git clone --recurse-submodules https://github.com/miqu-project/miqu-project.git
cd miqu-project

# Run deterministic multi-stage build
./install_all.sh
