Compositor IPC Controls & miquctl

The authoritative technical guide for the miquland Inter-Process Communication architecture, the first-party miquctl controller CLI, state query schemas, window management dispatchers, real-time event streaming, and graceful desktop shutdown orchestration.

1. Architecture & Socket Discovery

miquland initializes a dedicated Unix Domain Socket during startup. The IPC server integrates directly into the Wayland event loop using wl_event_loop_add_fd(), ensuring non-blocking execution, thread confinement to the compositor main thread, and strict compliance with the 0.0% idle CPU utilization doctrine.

Socket Path Resolution Order
  1. $MIQULAND_SOCKET (explicit environment override, automatically imported into systemd --user)
  2. $XDG_RUNTIME_DIR/miquland-$WAYLAND_DISPLAY.sock (default runtime location, e.g. /run/user/1000/miquland-wayland-0.sock)
  3. /tmp/miquland-$UID-$WAYLAND_DISPLAY.sock (unprivileged fallback)

2. Binary Framing & Fallback Wire Protocol

Communication between clients and the compositor is framed using an efficient, length-prefixed binary header, ensuring zero message tearing:

Field Size Type Value / Description
Magic 4 Bytes char[4] "MIQU"
Message Type 4 Bytes uint32_t (LE) 0 = Command, 1 = Subscribe, 2 = Response, 3 = Event
Payload Length 4 Bytes uint32_t (LE) Length in bytes of JSON payload
Payload Variable char[] UTF-8 JSON string or command string
Plain-Text Shell Fallback

For maximum developer ergonomics, the IPC server also automatically recognizes plain newline-delimited ASCII strings. You can pipe shell commands directly via socat or nc without packaging binary headers:

Shell Example 
echo "workspaces" | nc -U /run/user/1000/miquland-wayland-0.sock

miquctl cursor [theme] [size]

Query active pointer theme and pixel size, or dynamically hot-swap cursor assets in RAM across all seat pointers without restarting the compositor. Pass -j for machine-readable JSON:

Terminal CLI Output 
# Human-readable query
$ miquctl cursor
Cursor: Qogir (30px)

# Live hot-swap across all pointers
$ miquctl cursor Bibata-Modern-Classic 24
Cursor: Bibata-Modern-Classic (24px)
JSON Response (--json) 
{
  "theme": "Qogir",
  "size": 30
}

4. Comprehensive Window & Workspace Dispatchers

Issue real-time window management commands and trigger compositor state transitions directly from scripts, terminal keybindings, or gestures:

Command Description
miquctl dispatch close [id]Sends an XDG polite close request to targeted window (or active focused window)
miquctl dispatch kill [id]Forcefully destroys Wayland client connection for target window
miquctl dispatch focus <left|right|up|down>Moves keyboard focus directionally using 2D Euclidean geometry bounding box calculations
miquctl dispatch focus <next|prev|id>Cycles keyboard focus to next/prev window or directly focuses window by numeric ID
miquctl dispatch move <dx> <dy> [id]Moves floating window by delta pixels relative to current position
miquctl dispatch moveto <x> <y> [id]Moves floating window to absolute coordinates
miquctl dispatch resize <dw> <dh> [id]Resizes floating window by delta pixels, or adjusts tiling split ratio on active workspace
miquctl dispatch resizeto <w> <h> [id]Sets floating window to absolute dimensions (minimum 100x80)
miquctl dispatch workspace <id>Switches the active workspace to workspace <id>
miquctl dispatch movetoworkspace <id> [id]Moves focused window (or specified window ID) to workspace <id>
miquctl dispatch toggle_floating [id]Toggles floating/tiling state of target or active window
miquctl dispatch toggle_fullscreen [id]Toggles true fullscreen mode for target or active window
miquctl dispatch toggle_layoutToggles workspace layout engine between Fibonacci Spiral and Stack
miquctl dispatch swap_main [id]Swaps target or active window with the master column window
miquctl dispatch toggle_splitToggles layout split direction between horizontal and vertical
miquctl dispatch shutdown [timeout_ms]Triggers compositor-native graceful shutdown sequence (default timeout: 2500ms)
miquctl gaps [inner] [outer]Gets or dynamically modifies window inner gaps, outer screen edge padding, and smart gaps in RAM
miquctl border [width] [radius] [active] [inactive]Gets or dynamically updates border width, corner radius, active/inactive gradient hex colors, and shading in RAM
miquctl cursor [theme] [size]Gets or hot-swaps active XCursor / wl_cursor theme and size across all pointer devices in RAM
miquctl setoption <name> <value>Dynamically sets any configuration option in RAM (e.g. gaps_in, border_radius, smart_gaps, cursor_theme) with immediate relayout and damage redraw
miquctl getoption [name]Queries active runtime value of a configuration option, or dumps all runtime options if omitted
miquctl reloadHot-reloads miquland.conf configuration on the fly
miquctl exec <command>Executes a program in the compositor session environment
miquctl exitTerminates the compositor session immediately

5. Graceful Desktop Shutdown Orchestrator

Traditional compositor termination or crude shell scripts running killall or pkill abruptly sever applications, causing text editors, IDEs, and browsers to lose unsaved work. miquctl shutdown provides an intelligent, protocol-driven shutdown workflow orchestrated natively by miquland:

Stage 1

Polite Close Broadcast

miquland broadcasts standard XDG polite close requests (xdg_toplevel_send_close) to all top-level application windows. Applications prompt the user to save unsaved documents.

Stage 2

Event-Driven Unmap Watcher

The compositor monitors view unmap events with a hardware timer fallback. If all windows close cleanly before the timeout, teardown executes immediately with zero unnecessary waiting.

Stage 3

Clean Session Teardown

Broadcasts session shutdown event, sends SIGTERM to all tracked autostart process groups (miqubar, miqudesk, miqunotify, etc.), severs client display sockets, and exits.

Flag Default Description
--timeout <ms>3000Maximum duration in milliseconds to wait for applications to close
--forcefalseForce immediate compositor exit without waiting for applications
--dry-runfalseInspect open windows that would be closed without executing
--no-exitfalseClose all application windows without quitting miquland
--post-cmd <cmd>""Execute power action after exit (e.g. "systemctl poweroff")

Common Power Action Recipes

Graceful System Poweroff 
miquctl shutdown --post-cmd "systemctl poweroff"
Graceful System Reboot 
miquctl shutdown --post-cmd "systemctl reboot"

6. Real-Time Event Subscriptions

Rather than polling the compositor at fixed intervals (which wastes battery and CPU), client applications and status bars (such as miqubar or waybar) can subscribe to instant event broadcasts:

Subscribe Command 
miquctl subscribe workspace window monitor shutdown
Event Channel Trigger Action Payload Schema Example
workspace Workspace switched {"event":"workspace","data":{"action":"switch","workspace_id":2,"prev_workspace_id":1}}
window Window mapped / opened {"event":"window","data":{"action":"map","id":1,"title":"kitty","app_id":"kitty","workspace_id":1}}
window Window unmapped / closed {"event":"window","data":{"action":"unmap","id":1,"title":"kitty","app_id":"kitty","workspace_id":1}}
window Focus changed {"event":"window","data":{"action":"focus","id":1,"title":"kitty","app_id":"kitty","workspace_id":1}}
window Title updated {"event":"window","data":{"action":"title","id":1,"title":"vim: file.cpp"}}
monitor Output connected / disconnected {"event":"monitor","data":{"action":"connect","name":"DP-1"}}
shutdown Compositor teardown initiated {"event":"shutdown","data":{"status":"initiated","timeout_ms":2500}}

The socket connection remains open, streaming newline-delimited JSON events with 0ms latency whenever workspaces switch, windows map or unmap, or monitor resolutions update.

XDG Desktop Portals & Screen Sharing

Currently, the Miqu ecosystem does not maintain a dedicated bespoke portal daemon (such as xdg-desktop-portal-miqu). Instead, miquland natively implements modern Wayland capture protocols and integrates directly with proven standard backends:

Screen & Window Capture

Delegated to xdg-desktop-portal-wlr. Powered by ext-image-copy-capture-v1, ext-foreign-toplevel-list-v1, and ext-foreign-toplevel-image-capture-source-v1 for smooth, deadlock-free streaming in OBS Studio, Discord, and WebRTC browsers.

File Choosers & Dialogs

Delegated to xdg-desktop-portal-gtk for native, standard GTK file picker dialogs, notifications, and application pickers.

System Configuration Baseline

The authoritative portal configuration is placed in the system path at /usr/share/xdg-desktop-portal/miquland-portals.conf:

/usr/share/xdg-desktop-portal/miquland-portals.conf 
[preferred]
default=gtk
org.freedesktop.impl.portal.ScreenCast=wlr
org.freedesktop.impl.portal.Screenshot=wlr

User Customization & Overrides

To customize or override these portal rules, write your own miquland-portals.conf in your user configuration directory:

User Override Path 
~/.config/xdg-desktop-portal/miquland-portals.conf

Any settings defined in this user file will automatically take precedence over the system default without modifying system files.
